# סרטון פרסומי – גמ״ח החסד של דניאל אשוש

סרטון אנכי 9:16 ‏(1080×1920, ‏30fps), באורך כ־50 שניות, לסטטוס וואטסאפ ולרשתות. האורך נקבע לפי הקריינות, בלי הפסקות ריקות.
הקובץ הסופי: `output/gmach-daniel-ashush-promo.mp4`

## מבנה הסרטון

| זמן | קטע | מה רואים |
|---|---|---|
| 0–7 | פתיחה | צילומי מוצרים אמיתיים מהגמ״ח עם תנועת מצלמה ודירוג צבע קולנועי, ו־"0 ₪" בזהב |
| 7–19 | הצגת הגמ״ח | חשיפת הלוגו המקורי, ואז מונטאז' מוצרים בקצב המוזיקה (מקרר, ספה, כוננית, תנור, ארון, מיטה, רמקולים) |
| 19–34 | הצצה לסטטוס | ההקלטה המקורית בתוך מסגרת טלפון (כ־9 שניות), כפתורי שיחה/וואטסאפ, ושעון של 15 דקות שמתרוקן עד "נמסר!" |
| 34–46 | הטבות | "וזה עוד לא הכול!", קופון, מתנה ותג הנחות עם קונפטי |
| 46–60 | סיום | הלוגו, כרטיס הצטרפות עם תמונת הפרופיל, טקסט הסיום, כפתור "הצטרפו עכשיו!" ומקום ריק לקישור |

## פרטיות

`prep_rec.py` משתמש רק בקטעים מההקלטה שאין בהם כותרות צ'אט או שמות פרטיים (5.35–10.15 ו־15.25–19.7 שניות).
הוא מזהה בכל פריים את מספרי הטלפון של המוסרים (הקישורים הירוקים) ומטשטש אותם, יחד עם העותק המוגדל שמופיע ברקע הכהה של הסטטוס.
המספר של הגמ״ח עצמו (050-816-5833) נשאר גלוי, ומופיע גם במסך הסיום.

## הפקה מחדש

```bash
S=/path/to/assets            # תיקיית עבודה
python3 prep_rec.py RECORDING.mp4 $S/work
python3 music.py $S/music.wav
python vo.py $S/vo           # דורש torch + transformers (facebook/mms-tts-heb + openai/whisper-small)
python3 render.py $S out.mp4 # דורש בתיקייה: full/*.jpg, logo.png, portrait.jpg
python3 mix.py $S $S/mix.wav
ffmpeg -i $S/video_only.mp4 -i $S/mix.wav -c:v copy -c:a aac -b:a 192k -shortest out.mp4
```

- **הלוגו:** לוגו יוקרתי בזהב מתכתי נוצר ב־`make_logo.py` (`python3 make_logo.py $S/logo.png`). אפשר להחליף אותו בכל PNG שקוף בשם `logo.png` ולהריץ שוב את `render.py`.
  קבצי הלוגו לשימוש חופשי: `output/logo-gmach-daniel-ashush.png` (רקע שקוף) ו־`output/logo-preview-dark.jpg`.
- **להכנסת הקישור לתוך המסגרת:** `LINK_TEXT="wa.me/…" python3 render.py …`
- **להחלפת הקריינות בקול אנושי:** מקליטים כל משפט מ־`script.py` כקובץ `vo/<id>.wav` ‏(48kHz), מעדכנים את `vo/vo.json` עם המשכים, ומריצים שוב את `render.py` ואת `mix.py`. הכתוביות מסתנכרנות לבד.
- המוזיקה מסונתזת במלואה בקוד (`music.py`), ולכן אין בעיית זכויות.

## עדכון: תמונות, קריינות וקצב

- **תמונות המוצרים** בפתיחה ובמונטאז' הן צילומי אווירה באיכות גבוהה מ־Unsplash. הרישיון מתיר שימוש מסחרי בלי חובת קרדיט. רשימת התמונות נמצאת ב־`assets/unsplash_photos.json`, וכל אחת זמינה בכתובת `https://unsplash.com/photos/<id>`.
  את התמונות מורידים לתיקייה `un/hi/<name>.jpg` בתוך תיקיית העבודה.
- **הקריינות:** הקול הגברי he-IL-AvriNeural של Microsoft, דרך `vo_edge.py` (חבילת `edge-tts`). כל קטע מוקלט כטייק רציף אחד לטבעיות. זמני המילים שהשירות מחזיר משמשים לסנכרון הכתוביות.
  `RATE=+10%` קובע את קצב הדיבור, ו־`VOICE` מאפשר להחליף קול.
- **הקצב:** המוזיקה ב־120 BPM. במונטאז' מתחלף מוצר בכל שתי פעימות (שנייה אחת), והמעברים הם טשטוש תנועה מהיר. `music.py` מקבל את `timeline.json` שמייצר `render.py`.

סדר ההרצה המעודכן:
```bash
python3 vo_edge.py $S/vo2
python3 render.py $S out.mp4          # מייצר גם את $S/timeline.json
python3 music.py $S/music.wav $S/timeline.json
python3 mix.py $S $S/mix.wav
```
