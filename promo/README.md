# סרטון פרסומי – גמ״ח החסד של דניאל אשוש

סרטון אנכי 9:16 ‏(1080×1920, ‏30fps), באורך 60 שניות, לסטטוס וואטסאפ ולרשתות.
הקובץ הסופי: `output/gmach-daniel-ashush-promo.mp4`

## מבנה הסרטון

| זמן | קטע | מה רואים |
|---|---|---|
| 0–7 | פתיחה | צילומי מוצרים אמיתיים מהגמ״ח עם תנועת מצלמה ודירוג צבע קולנועי, ו־"0 ₪" בזהב |
| 7–19 | הצגת הגמ״ח | חשיפת הלוגו המקורי, ואז מונטאז' מוצרים בקצב המוזיקה (מקרר, ספה, כוננית, תנור, ארון, מיטה, רמקולים) |
| 19–34 | הצצה לסטטוס | ההקלטה המקורית בתוך מסגרת טלפון (כ־9 שניות), כפתורי שיחה/וואטסאפ, ושעון של 15 דקות שמתרוקן עד "נחטף!" |
| 34–46 | הטבות | "וזה עוד לא הכול!", קופון, מתנה ותג הנחות עם קונפטי |
| 46–60 | סיום | הלוגו, כרטיס הצטרפות עם תמונת הפרופיל, טקסט הסיום, כפתור "הצטרפו עכשיו!" ומקום ריק לקישור |

## פרטיות

`prep_rec.py` משתמש רק בקטעים מההקלטה שאין בהם כותרות צ'אט או שמות פרטיים (5.35–10.15 ו־15.25–19.7 שניות).
הוא מזהה בכל פריים את מספרי הטלפון של המוסרים (הקישורים הירוקים) ומטשטש אותם, יחד עם העותק המוגדל שמופיע ברקע הכהה של הסטטוס.
המספר של הגמ״ח עצמו (050-816-5833, מתוך הלוגו) נשאר גלוי.

## הפקה מחדש

```bash
S=/path/to/assets            # תיקיית עבודה
python3 prep_rec.py RECORDING.mp4 $S/work
python3 music.py $S/music.wav
python vo.py $S/vo           # דורש torch + transformers (facebook/mms-tts-heb + openai/whisper-small)
python3 render.py $S out.mp4 # דורש בתיקייה: full/*.jpg, logo.png, portrait.jpg
python3 mix.py $S $S/mix.wav
ffmpeg -i $S/video_only.mp4 -i $S/mix.wav -c:v copy -c:a aac -b:a 192k -shortest out.mp4
```

- **להחלפת הלוגו בקובץ המקורי:** שמים PNG שקוף בשם `logo.png` (הוא נצבע אוטומטית בלבן) ומריצים שוב את `render.py`.
  הלוגו הנוכחי חולץ מסימן המים שעל התמונות בסטטוס, בלי שינוי בצורה.
- **להכנסת הקישור לתוך המסגרת:** `LINK_TEXT="wa.me/…" python3 render.py …`
- **להחלפת הקריינות בקול אנושי:** מקליטים כל משפט מ־`script.py` כקובץ `vo/<id>.wav` ‏(48kHz), מעדכנים את `vo/vo.json` עם המשכים, ומריצים שוב את `render.py` ואת `mix.py`. הכתוביות מסתנכרנות לבד.
- המוזיקה מסונתזת במלואה בקוד (`music.py`), ולכן אין בעיית זכויות.
