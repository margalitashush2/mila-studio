# מילה סטודיו

אפליקציה לתמלול עברית, כתוביות מעוצבות ועריכת וידאו לאייפון. היא רצה כולה על הטלפון, בחינם, בלי חשבונות ובלי שרתים.

## איך מתקינים באייפון

1. פותחים את קישור האפליקציה ב-**Safari** (לא בדפדפן אחר).
2. לוחצים על כפתור **השיתוף** (הריבוע עם החץ למעלה).
3. בוחרים **הוסף למסך הבית** ואז **הוסף**.
4. מעכשיו יש אייקון "מילה" במסך הבית, והאפליקציה נפתחת במסך מלא.

בתמלול הראשון יורד מנוע התמלול לטלפון (כ-790MB במנוע האיכותי, או כ-250MB במנוע הקל), ולכן כדאי להיות מחוברים ל-Wi-Fi. ההורדה קורית פעם אחת בלבד.

## מגבלות (חשוב לדעת)

- **אין הפרדת דוברים.** זיהוי דוברים דורש מודל נוסף שעוד לא שולב.
- **מהירות התמלול** תלויה בטלפון. באייפון חדש עם WebGPU זה מהיר. בטלפונים ישנים זה יכול לקחת בערך כמו אורך הסרטון, ויותר מזה.
- **הייצוא רץ בזמן אמת**: סרטון של דקה לוקח בערך דקה. צריך להשאיר את המסך פתוח בזמן הייצוא.
- **סרטונים ארוכים מאוד** (מעל כ-450MB) עלולים להיות כבדים מדי לזיכרון של הדפדפן.
- **המנוע הקל** לא מוסיף פיסוק, ולכן החלוקה למשפטים נעשית לפי הפסקות בדיבור.

## עלויות

**₪0.** אין שרתים ואין מנויים. האחסון (GitHub Pages) והמודלים (Hugging Face) חינמיים. הסרטונים לא יוצאים מהטלפון.

## ארכיטקטורה

- `src/core`: לוגיקה טהורה עם בדיקות: חלוקה לכתוביות, SRT, סידור כיווניות (bidi), חיתוכים ומיפוי זמנים, שתיקות ומילות מילוי, מילון.
- `src/asr`: תמלול על המכשיר (transformers.js ו-onnxruntime-web) ב-Web Worker. המודל נשמר ב-IndexedDB אחרי ההורדה הראשונה.
- `src/render`: מנוע ציור אחד לתצוגה המקדימה ולייצוא (Canvas), וייצוא עם MediaRecorder.
- `src/editor`, `src/screens`: הממשק (React, RTL מלא).
- `scripts/make-manifests.mjs`: מייצר את קובצי ההגדרה של המודלים, נעולים לגרסה מסוימת ב-Hugging Face.

## פיתוח

```bash
npm install
node scripts/make-manifests.mjs   # requires network access to huggingface.co
npm run dev
npx vitest run
npm run build
```
